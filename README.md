## 🍕 Pizza Sales Analysis — SQL & Power BI

## 📌 Project Overview

This project presents an end-to-end **Pizza Sales Analysis** using **SQL and Power BI** to analyze sales performance, customer ordering patterns, and product-level trends.

The project transforms raw pizza sales data into meaningful business insights through **SQL-based data analysis** and an interactive **Power BI dashboard**.

The dashboard provides a comprehensive view of sales across different **months, days, pizza categories, pizza sizes, and individual pizza products**, helping identify the best-performing products and overall sales trends.

---

## 🎯 Objectives

The main objectives of this project were to:

- Analyze overall pizza sales performance.
- Identify **daily and monthly sales trends**.
- Determine the **busiest days and months** based on orders.
- Analyze sales by **pizza category and size**.
- Identify the **best-selling and worst-selling pizzas**.
- Analyze revenue generated by individual pizza products.
- Understand customer ordering patterns.
- Build an interactive dashboard for business-level decision making.

## 🗄️ SQL Analysis

SQL was used to extract and analyze meaningful information from the dataset.

Some of the analysis included:

- Total revenue calculation
- Total orders and pizzas sold
- Average order value
- Revenue by pizza
- Top 5 pizzas by revenue
- Bottom 5 pizzas by revenue
- Revenue by category
- Revenue by pizza size
- Daily and monthly order trends
- Most popular pizzas

### Example SQL Query

```sql
SELECT 
    pizza_name,
    SUM(total_price) AS total_revenue
FROM pizza_sales
GROUP BY pizza_name
ORDER BY total_revenue DESC;
```
